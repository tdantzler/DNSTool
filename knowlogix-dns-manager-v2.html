Quick Reference: GHL DNS Setup CNAME A

When connecting a subdomain to GHL (funnels, sites, landing pages):

CNAME  →  host: sce-demo  →  value: sites.ludicrous.cloud (or whatever GHL shows)

A  →  host: sce-demo  →  value: 34.120.54.74 (typical GHL IP)

GHL will show you the exact records needed in Settings → Domains after you add the domain. Copy those values here.

Note: Name.com does NOT require cPanel or any hosting registration — DNS records alone are sufficient for subdomains pointed to external services like GHL.
